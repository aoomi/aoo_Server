# 内置第三方依赖隔离规范

- 历史构件仅保存在 `reference/legacy-2.22/third-party-maven-repository/com`，不属于 Maven 仓库、编译源或运行类路径；活动 `third-party/` 目录禁止存在。
- 生产依赖必须由受控 Maven 坐标解析；禁止 `systemPath`、`file:` 仓库、手工 `lib/` 和通配符类路径。
- 内置构件不得与 Maven 依赖或权威源码提供同名类；需要保留时必须迁入独立适配模块并显式声明。
- `scripts/audit-third02-maven-overlap.rb` 持续校验 POM 可达性、源码同类和已解析运行依赖同类冲突。
