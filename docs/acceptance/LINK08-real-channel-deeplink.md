# LINK08 真实渠道深链后置验收

## 前置条件

- 微信正式/测试开放平台回跳域名已备案并加入白名单。
- iOS Universal Link、Android App Link 和 Web fallback 使用同一签名邀请格式。
- 准备未安装、未登录、已登录大厅、已在其他房间、版本不兼容五类独立账号/设备状态。

## 必测矩阵

| 渠道 | 初始状态 | 预期链路 | 必留证据 |
|---|---|---|---|
| 微信 | 未安装 | 商店/下载页 -> 安装 -> 登录 -> 恢复邀请 -> 服务端准入 | 录屏、inviteId、traceId |
| 微信 | 未登录 | 登录 -> 恢复邀请 -> 目标房间 | 录屏、traceId |
| Safari/Chrome | 大厅 | 验签 -> 目标房间 | HAR、traceId |
| 原生 App | 其他房间 | 二次确认 -> 离房成功 -> 目标房间 | 录屏、旧/新 roomId |
| 全渠道 | 版本不兼容 | 升级提示 -> 升级 -> 恢复邀请 | 录屏、前后版本 |

## 失败路径

- 过期、篡改、已撤销邀请必须停留安全页面，不能尝试加入。
- 回跳取消、登录取消、升级取消均保留可重试入口但不得循环拉起。
- 每次最终加入必须重新调用服务端准入，客户端缓存不作为权限依据。

## 结论

当前自动化前置状态机、签名、撤销和准入门禁已具备。真实微信/浏览器/原生渠道登录态与回跳证据需要发布环境和设备，集中列入最终人工验收。
