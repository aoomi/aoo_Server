# 源码与生成物边界规范

## 1. 权威源码

- Java 权威源码只允许位于各模块的 `src/main/java`、`src/test/java` 及明确登记的兼容源码根。
- 协议、数据库迁移、配置和资源清单的权威输入分别位于 `protocol/`、`database/migrations/`、模块配置目录和资源目录。
- `server/LegacyCommon/src`、`server/LegacyCommDef/src` 是受控兼容源码根；其中生成文件必须登记来源，禁止手工修改。

## 2. 临时生成物

- Maven/工具临时输出只允许进入 `target/`、`build/`、`work/audit/` 或 `work/runtime/`。
- 临时输出必须同时被 `.gitignore` 与 `.releaseignore` 隔离，不得写入源码或日志目录。

## 3. 可提交生成物

- 可审阅文档和清单统一写入 `docs/generated/`。
- 所有可提交生成物必须登记在 `docs/generated/generated-artifact-manifest.json`，包含权威输入、生成器、重建命令、所有者和编辑策略。
- 生成物禁止手工编辑；更新权威输入后必须通过登记命令重建。
- 遗留兼容生成源码可保留在兼容源码根，但必须具备可追溯权威输入和生成器。
- 一次性迁移清单允许登记已清理的 \`optionalInputs\`；生成器本身仍是必须保留的权威重建输入。

## 4. 门禁

`scripts/audit-hygiene12-generated-boundary.rb` 校验生成清单覆盖率、输入与生成器存在性、生成 Java 边界和临时目录发布隔离。根 Maven `validate` 阶段强制执行该门禁。
