# 集成测试可重复入口

所有 AI、本地开发与 CI 必须使用 `tools/verify-clean-with-integration-db.sh` 执行 Server 最终验证，不得直接依赖 shell 中偶然存在的 `AOO_DB_IT_*`，也不得用跳过的集成测试签署。

1. 复制 `.env.integration.example` 为被 `.gitignore` 和 `.releaseignore` 排除的 `.env.integration.local`，执行 `chmod 600 .env.integration.local`。
2. 本地推荐指定专用 MySQL 8 测试容器；CI 应从 secret store 注入外部测试库密码。
3. 执行 `tools/verify-clean-with-integration-db.sh`。

入口会验证凭据文件权限，创建名称受限的 `aoo_it_*` 任务隔离 schema，执行全部 Flyway migrations，写入确定性测试 fixture，注入集成测试连接，再原样执行 `./mvnw clean verify`。缺少数据库、凭据、JDK 或 mysql/docker 能力时立即失败；不会静默 skip。默认在退出时只删除本次精确创建的隔离 schema，不会连接或修改生产库。
