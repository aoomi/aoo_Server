# 必要插件产物追踪

| 插件/导入器 | 阶段 | 输入 | 生成/发布产物 | 消费方 | 删除影响 | 保护方式 |
|---|---|---|---|---|---|---|
| Lombok annotation processor | compile | 1,510 个 Lombok 注解源类 | getter/setter/builder/构造器字节码 | 服务模块直接链接 | 大量源码无法编译或 ABI 缺失 | `annotationProcessorPaths` 显式锁定，UNUSED09 门禁 |
| build-helper-maven-plugin | generate-sources | `server/common/src`、`server/commdef/src` | gameServer 共享源集纳入编译 | gameServer compiler/jar | 基础类与协议 DTO 缺失 | 执行 ID `shared-sources`、UNUSED08 执行台账 |
| maven-dependency-plugin | package | account `hall` reactor 制品 | `package_hall/target/lib` 运行依赖集 | 大厅发布包 | 发布包启动时 ClassNotFound | 显式 copy-dependencies 执行和产物目录检查 |
| maven-resources-plugin | process-resources | account 配置/资源 | package_hall 资源树 | 大厅启动器 | 运行配置与协议资源缺失 | Maven 标准生命周期 + UNUSED07 |
| maven-jar-plugin | package | compiled classes + mainClass | 26+ 模块 Jar 与启动 manifest | Bootstrap/各独立服务 | 无法发布或 `java -jar` 启动 | UNUSED27 制品数和启动样本 |
| exec-maven-plugin audit suite | validate | POM、源码、资源、运行证据 | `work/audit/*.json` 与构建准入结论 | CI/Maven reactor | 架构、安全和兼容回归无法阻断 | UNUSED08/30 检查执行唯一且输出被消费 |
| Cocos Creator 3.8.8 asset importer | editor import/build | `.prefab/.scene/.png/.plist/.atlas/.json` 及 `.meta` UUID | Library/import 结果、web-desktop 包、UUID 关联 | Creator 编辑器与客户端运行时 | 预制体不可打开、图集/Spine/图片丢失 | 保留受引用 `.meta`，UNUSED18/19/21 资源门禁 |
| jprotobuf runtime schema | runtime conversion | `@Protobuf` DTO 及历史字段号 | 运行时 codec/schema 结果 | account/game 协议适配器 | 2.22 二进制协议无法读写 | 字段号/类型兼容测试，禁止按无生成目录误删 |

产物追踪以“输入 -> 执行阶段 -> 产物 -> 消费方 -> 回归证据”为完整链；不能因插件不在运行 classpath 就判定无用。
