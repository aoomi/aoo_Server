# 后端环境变量配置

仓库配置文件不保存真实凭据。部署前由密钥管理系统、容器编排平台或进程环境注入以下变量。

## 主游戏服

`CommProperties` 将配置键转换为大写，并把非字母数字字符转换为下划线，前缀固定为 `QH_`。

| 环境变量 | 用途 |
| --- | --- |
| `QH_CLARK_GAME_PASSWORD` | `db.properties` 主游戏库密码 |
| `QH_CLARK_LOG_PASSWORD` | `db.properties` 日志库密码 |
| `QH_DB_ZLE_PASSWORD` | `db.properties` ZLE 库密码 |
| `QH_DB_PASSWORD` | `game.properties` / `type.properties` 主游戏库密码 |
| `QH_LOGDB_PASSWORD` | `game.properties` / `type.properties` 日志库密码 |
| `QH_ZLEDB_PASSWORD` | `game.properties` / `type.properties` ZLE 库密码 |
| `REDIS_PASSWORD` | Redis 密码 |
| `MONGODB_USERNAME` | MongoDB 用户名 |
| `MONGODB_PASSWORD` | MongoDB 密码 |

数据库 URL、用户名等非密钥配置也可以使用同一 `QH_` 规则覆盖。例如 `clark_game.url` 对应 `QH_CLARK_GAME_URL`。

## 账号服务

| 环境变量 | 用途 |
| --- | --- |
| `ACCOUNT_TOKEN_SECRET` | 登录 Token 签名密钥，生产环境必填 |
| `ACCOUNT_WECHAT_APP_ID` | 微信 App ID |
| `ACCOUNT_WECHAT_SECRET` | 微信应用密钥 |
| `ACCOUNT_DB_USER` | 主账号库用户名 |
| `ACCOUNT_DB_PASSWORD` | 主账号库密码 |
| `ACCOUNT_LOG_DB_USER` | 日志库用户名 |
| `ACCOUNT_LOG_DB_PASSWORD` | 日志库密码 |
| `ACCOUNT_ZLE_DB_USER` | ZLE 库用户名 |
| `ACCOUNT_ZLE_DB_PASSWORD` | ZLE 库密码 |
| `ACCOUNT_REDIS_PASSWORD` | Redis 密码 |
| `ACCOUNT_MONGODB_USER` | MongoDB 用户名 |
| `ACCOUNT_MONGODB_PASSWORD` | MongoDB 密码 |

## 安全要求

AdminApi 地图代理使用 `ADMIN_MAP_PROVIDER_KEY` 对应的 Secret 引用（例如 `secret://env/ADMIN_MAP_PROVIDER_KEY`）。
密钥只由服务端 Secret provider 解析，不得注入 Admin 前端构建环境、响应、日志或仓库。

- 生产环境禁止使用空密码或示例密码。
- 密钥不得写入源码、启动脚本、命令行参数或普通日志。
- 按环境使用不同凭据，并通过密钥管理服务定期轮换。
- `ACCOUNT_TOKEN_SECRET` 轮换会使旧 Token 失效，应安排兼容窗口。
