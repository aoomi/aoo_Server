# 迁移暂存与生成目录分类规范

| 类别 | 机器分类 | 目录模式 | 生产发布 | 处理规则 |
|---|---|---|---|
| Maven 生成物 | `maven-generated` | `**/target` | 禁止 | 可重建，不作为源码或迁移证据 |
| 遗留构建产物 | `legacy-build-output` | `server/*/build` | 禁止 | 仅兼容对照，运行入口不得读取 |
| 本地运行产物 | `local-runtime-output` | `work/runtime`、`work/local-runtime`、`server/*/work/runtime` | 禁止 | 测试会话结束可清理，禁止写入类路径清单 |
| 工具链对照 | `toolchain-reference` | `work/jdk8`、`work/toolchains` | 禁止 | 仅审计参考；正式构建由外部 `JAVA_HOME` 驱动 |
| 迁移源码 | `migration-source` | `test-move`、`**/source-project` | 禁止直接运行 | 每文件必须有迁移矩阵，未分类即门禁失败 |
| 历史参考 | `historical-reference` | `reference`、`**/Archive` | 禁止 | 只读、哈希留档、与生产依赖隔离 |
| 生成缓存 | `generated-cache` | `**/library`、`**/temp` | 禁止 | 可重建，禁止作为输入或发布内容 |

任何新增同类目录必须先进入自动清册。分类不等于允许发布或允许运行。
