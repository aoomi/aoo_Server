# 发布类路径最小化规范

- 发布依赖只允许来自 Maven runtime scope；test、provided、历史 reference、本地 lib 和旧 build 产物不得进入。
- 当前发布包使用平台无关 Java NIO，不携带 Linux、macOS、Windows、x86_64、aarch64、riscv64 的 Netty/QUIC 本地构件。
- 依赖不得靠通配符或目录扫描扩张；每个实际发布 Jar 必须进入哈希清单。
- 若未来启用本地传输或 QUIC，应按目标平台建立独立发布变体，不得在一个包中混装所有平台。

scripts/audit-third10-release-minimization.rb 同时检查 POM 规则和已生成发布目录（存在时）的真实内容。
