# 类加载与运行类路径规范

- 编译、单测、集成测试和发布均以 Maven reactor 的 dependencyManagement 解析结果为唯一依赖来源。
- 本地启动只读取模块 target/classes 与 Maven 生成的 target/runtime-classpath.txt；禁止手工 lib、通配符、reference 或历史 build 目录。
- 生产启动只允许 reactor 产物和 Maven 解析依赖；历史兼容构件不得注入。
- 当前项目没有容器发布定义；后续新增容器必须复用 Maven 发布清单并通过同一类路径门禁。
- test scope 只允许增加测试工具，不得替换 main scope 的第三方实现。
