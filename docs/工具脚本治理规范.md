# Aoo 工具脚本治理规范

- 每个 Ruby、Python、Shell 工具必须有解释器声明、内容哈希版本、语法校验结果和副作用分类。
- `read-only-audit` 只能读取源码并覆盖自身证据；`repeatable-generator` 必须原子覆盖确定输出；`controlled-side-effect` 必须显式参数、范围限制、dry-run 或二次许可。
- 数据库删除、缓存删除、进程终止、批量文件清理和生产网络调用不得以默认参数执行。
- `.class`、Python 字节码和工具临时输出不得与工具源码同目录。
- 语法通过不等于语义通过；每个工具还需有 Maven 门禁、自动化测试或可重复的隔离运行证据。
