# API 行为变更日志

## 2.0.0（2026-08-23）

| 受众 | 协议/入口 | 类型 | 行为变化 | 迁移说明 |
|---|---|---|---|---|
| 前端、运维、客服 | WSS `common.*` | 安全 | 游戏权威操作统一使用带序号、幂等号和玩法版本的 V2 帧 | 客户端切换至 `*_req`；运维封锁旧监听；客服提示升级客户端 |
| 前端、运维、客服 | HTTP `/api/v2/admin/game-profiles` | 新增 | 玩法版本发布与回滚进入独立管理控制面 | 使用独立管理域名和发布权限 |

程序查询入口为 `ApiChangeLog`，文档与代码条目必须在同一变更中更新。
