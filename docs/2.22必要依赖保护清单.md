# 2.22 必要依赖保护清单

## 判定规则

本清单只保护仍支撑真实业务、历史数据或迁移输入的能力，不把 2.22 旧运行时整体带入新架构。任一条目在“等价替代”未完成输入/输出、异常、并发、平台和历史格式回归前禁止删除。

| 能力/依赖 | 当前受控实现 | 支撑功能 | 调用方式/边界 | 数据格式 | 插件/产物 | 缺失影响 | 等价替代判定 |
|---|---|---|---|---|---|---|---|
| Disruptor | `com.lmax:disruptor:4.0.0` | 账号与游戏服务的有界事件/批量日志消费 | dispatcher 和 logger/flow 基础设施调用，玩法不直调 | JVM 内事件对象、批量 DB 日志 | 无生成代码；运行 Jar | 事件丢失、日志积压或服务启动失败 | 需证明顺序、背压、关停排空和故障恢复等价 |
| OkHttp | `com.squareup.okhttp3:okhttp-jvm:5.3.0` | 微信/手机/平台 SDK HTTP 调用 | account common HTTP adapter，禁止玩法层直调 | HTTPS JSON/form/二进制响应 | 运行 Jar | 登录与平台鉴权中断 | 需证明超时、TLS、连接池、重试和错误映射等价 |
| Apache MINA | `org.apache.mina:mina-core:2.2.9` | 2.22 WebSocket/内部传输过渡兼容 | 仅 `common/websocket` 与 `client2game` legacy adapter | 历史二进制帧和事件名 | 运行 Jar | 尚未切断的旧客户端/节点无法传输 | 新 Netty/WSS 必须通过帧语义、时序和重连回归后才可移除 |
| Gson | `com.google.code.gson:gson` | 历史协议 DTO、Redis/Mongo 存量 JSON 和玩法回放转换 | 限 legacy DTO/持久化适配边界 | 2.22 JSON 字段名、默认值和容错形状 | 运行 Jar | 历史配置、房间或回放无法读取 | Jackson 转换器必须通过历史样本逐字段回归 |
| Fastjson2 compatibility | `com.alibaba.fastjson2:fastjson2` | 存量 Fastjson 形状的受控读写 | 仅兼容 adapter，禁止不受控 AutoType | 历史 JSON/类型标记 | 运行 Jar | 部分存量数据无法升级读取 | 需安全负测与历史样本回归 |
| Joda-Time | `joda-time:joda-time:2.14.3` | 存量时间计算和序列化兼容 | 限旧工具/数据 adapter，新代码用 `java.time` | 历史时区、时间戳和日期字符串 | 运行 Jar | 定时、账务日切或历史时间解析偏移 | 需时区/DST/日切样本等价 |
| Commons Codec/IO | `commons-codec:1.22.1` / `commons-io:2.21.0` | 历史签名、编码、文件/资源读取 | 限安全与迁移工具边界 | Base64/Hex/哈希、历史文件字节 | 运行/转换工具 Jar | 签名不兼容、资源导入失败 | JDK API 替代需黄金向量与文件字节一致 |
| RocketMQ client | `org.apache.rocketmq:rocketmq-client:5.5.0` | 跨服房间、账务、亲友圈事件 | infrastructure MQ adapter/SPI | 有版本的事件 envelope、aggregate key | 运行 Jar，zstd-jni 为 SDK 自管压缩产物 | 跨节点事件中断或乱序 | 需顺序、幂等、重试、DLQ 和恢复注入等价 |

## 删除保护

1. 删除前必须附带用途扫描、调用边界、替代映射、历史数据测试、产物比较和负责人结论。
2. 新业务不得扩大 MINA、Gson、Fastjson2、Joda-Time 的可达范围。
3. 该清单与 `UNUSED26` 历史格式回归、`UNUSED27` 产物比较、`UNUSED28` 全链验证共同构成删除前置证据。
