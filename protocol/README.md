# Aoo 协议机器源

`aoo-protocol-v2.json` 是新接口信封、字段和错误码分区的唯一机器源。客户端生成类型，不得手工维护第二套协议定义。

## 兼容策略

- V1：现有 `event + signed int16 sequence + signed int16 errcode + JSON`，只修缺陷，不新增架构能力。
- V2：统一 HTTP/WebSocket 字段，序号使用正整数，错误码使用机器协议源登记的稳定整数；客户端只按错误码分支，不解析提示文字。
- 网关在握手或请求头协商版本；同一连接只使用一种主版本。
- 旧玩法按登录、大厅、亲友圈、公共房间、子游戏顺序迁移，禁止一次性破坏旧协议。
- V2 DTO 必须从契约生成；构建时比较生成结果，不一致则失败。
- 每条消息必须声明方向、传输、鉴权、写属性、幂等模式、请求/响应结构和错误码；缺项时生成与 CI 直接失败。

## 命名

- 消息类型使用机器源登记的固定聚合 `msgId`，具体动作放在 `body.action`。
- 请求/响应共用 `requestId`；推送使用登记的 `state_push`，序号由服务端递增生成。
- 字段使用 lowerCamelCase；ID 在 JSON 中使用字符串，避免 H5 大整数精度丢失。
- 时间统一 Unix 毫秒；HTTP 与 WSS 统一信封字段，不使用 `data/result` 平行结构。
