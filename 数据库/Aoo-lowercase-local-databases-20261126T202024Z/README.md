# 小写 aoo 本地数据库交付

本目录只包含 `/Users/aoo/Code/Game/aoo` 当前运行栈有配置、进程归属和实际 TCP 连接共同证明正在使用的业务库：MySQL 8.0.46 实例 `127.0.0.1:3306` 上的 `aoo_login_local`。

## 内容

- `dumps/aoo_login_local.sql.gz`：结构和数据一致性导出，包含表、视图、触发器、存储过程和事件。
- `INSTANCE_INVENTORY.md`：实例、使用证据和排除边界。
- `OBJECT_COUNTS.tsv`：源库与隔离恢复后的对象数。
- `TABLE_ROW_COUNTS.tsv`：367 张基础表的源库与隔离恢复精确行数对账。
- `DEFINERS.tsv`：例程、触发器和事件的 definer 清单，便于导入前权限审查。
- `IMPORT_ORDER.md`：导入步骤和验证要求。
- `CHECKSUMS.sha256`：交付文件校验和。
- `evidence/`、`restore-validation/`：脱敏运行证据与同版本隔离恢复证据。

## 安全属性

- 目录权限为 `0700`，普通文件为 `0600`。
- 导出使用单事务、流式读取且跳过表锁；未修改、删除或停止源数据库。
- 未连接远程服务器，未执行 Git 操作；用于执行导出的数据库凭据、环境变量和命令认证材料没有写入本交付或执行回执。
- `dumps/aoo_login_local.sql.gz` 是**未脱敏的完整业务备份**，可能包含认证哈希、用户标识、Token 关联字段以及牌局和其他业务数据。必须按敏感备份管理，仅允许已授权人员访问；不得提交到 Git，不得粘贴到聊天，也不得放入普通共享存储。
- 隔离恢复容器未映射端口、禁用网络，验证结束后已停止。

## 验证结论

`gzip -t` 通过；同版本 MySQL 8.0.46 隔离恢复成功；源/恢复的 367 张基础表、9 个视图、4 个存储过程、24 个触发器及每张基础表精确行数完全一致。事件数为 0。
